# Механіки виживання — Proiect de Legume

## Філософія

Гравець повинен постійно балансувати між дослідженням світу та підтримкою свого стану.
Кожна дія має ціну: біг виснажує, їжа закінчується, рани сповільнюють.
Без зомбі головний ворог — час і власне тіло.

---

## Основні характеристики (v1) — РЕАЛІЗОВАНО

### 1. Голод (Hunger) ⭐ Пріоритет: ВИСОКИЙ
- **Діапазон:** 0–100 (починає з 80)
- **Зменшення:** -1 кожні 30 секунд в стані спокою
- **Модифікатори:**
  - Біг (Shift): x2 витрата голоду
  - Велика вага інвентаря (>70% макс): x1.5 витрата
- **Ефекти низького голоду:**
  - < 30: швидкість руху -20%
  - < 15: зір зменшується (FOV радіус -30%)
  - 0: починає втрачати HP (-2 HP кожні 10 сек)
- **Відновлення:** їжа (canned_beans +25, water_bottle +10 голоду)

### 2. Спрага (Thirst) ⭐ Пріоритет: ВИСОКИЙ
- **Діапазон:** 0–100 (починає з 90)
- **Зменшення:** -1 кожні 20 секунд (швидше за голод)
- **Модифікатори:**
  - Біг: x2.5 витрата
- **Ефекти низької спраги:**
  - < 30: швидкість руху -25%
  - < 15: екран трохи розмивається / затемнюється по краях
  - 0: -3 HP кожні 10 сек
- **Відновлення:** water_bottle +40 спраги

### 3. Втома (Fatigue) ⭐ Пріоритет: ВИСОКИЙ
- **Діапазон:** 0–100 (100 = повністю відпочив, 0 = виснажений)
- **Зменшення:**
  - Ходьба: -0.5/хв
  - Біг: -3/хв
  - Стояння на місці: -0.1/хв
  - Голод < 30: додаткові -1/хв
  - Вага > 70% макс: додаткові -0.5/хв
- **Ефекти:**
  - < 40: не може бігти (Shift не працює)
  - < 20: швидкість руху -30%
  - < 10: поле зору -40%, екран затемнюється
- **Відновлення:** тільки сон (в майбутньому — ліжко)
  - Для v1: повільне відновлення коли стоїш на місці (+0.3/хв)

### 4. Здоров'я (HP) ⭐ Пріоритет: ВИСОКИЙ
- **Діапазон:** 0–100
- **Зменшення:**
  - Голод = 0: -2/10 сек
  - Спрага = 0: -3/10 сек
  - (В майбутньому: бій, падіння)
- **Відновлення:**
  - bandage: +15 HP
  - Повільна регенерація при голоді > 50 і спразі > 50: +0.5 HP/хв

## Додаткові механіки (v2+)

### 5. Температура (Temperature)
- **Діапазон:** Гіпотермія ← Нормально → Перегрів
- Залежить від одягу, часу доби, знаходження в будівлі
- Стара сорочка = +5 до теплоізоляції
- У будинку тепліше ніж надворі
- Наслідки: тремтіння (зменшення точності), втрата HP

### 6. Цикл дня та ночі
- 1 ігровий день = 10 хвилин реального часу
- Вночі: зменшений FOV, потрібен ліхтарик
- Flashlight: збільшує FOV вночі, але витрачає батарейки
- Освітлені будинки видно здалеку

### 7. Шум (Noise)
- Біг створює шум (підготовка для зомбі)
- Відкриття контейнерів = невеликий шум
- Шум візуалізується як пульсуючі кола навколо гравця
- Впливатиме на агро зомбі (у майбутніх версіях)

### 8. Психіка / Настрій (Morale)
- Нудьга від одноманітної їжі
- Читання газети = +5 настрій
- Низький настрій: повільніший рух, менший FOV
- Високий настрій: бонус до швидкості пошуку

### 9. Хвороби та поранення
- Порізи: від розбитого скла, потрібен бинт
- Інфекція: якщо поранення не оброблене вчасно
- Застуда: від низької температури, зменшує стамину
- Харчове отруєння: від зіпсованої їжі

### 10. Крафт (базовий)
- Газета + Сірники = Факел (тимчасове світло)
- Стара сорочка → Імпровізовані бинти (x2)
- Порожня банка + Вода = Повна банка води
- Викрутка + Дошки = Баррикада

### 11. Баррикади
- Закривати двері на засув
- Будувати баррикади з меблів
- Вікна (новий тип тайлу) можна закривати дошками

### 12. Псування їжі
- Їжа має термін придатності (кількість ігрових днів)
- Консерви: 30 днів (дуже довго)
- Свіжа їжа (якщо додамо): 2-3 дні
- Зіпсована їжа: ризик отруєння

## HUD: відображення характеристик

```
┌─────────────────────────────────────────────────────┐
│ ♥ HP  ████████████████░░░░  78/100                  │
│ 🍖 Hunger ███████████░░░░░░░░░  52/100              │
│ 💧 Thirst █████████████████░░░  85/100              │
│ 💤 Fatigue ██████████████░░░░░░  67/100             │
└─────────────────────────────────────────────────────┘
```

- Бари розташовані внизу-ліворуч
- Колір бару змінюється: зелений → жовтий → червоний
- При критичному рівні — пульсуюча анімація
- Іконки можна замінити текстом для v1
