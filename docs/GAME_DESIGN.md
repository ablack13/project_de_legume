# Proiect de Legume - Game Design Document

## Концепція

2D top-down survival гра, натхненна Project Zomboid. Поточна версія — без зомбі.
Гравець досліджує місто, обшукує будівлі та контейнери, збирає предмети,
їсть, п'є та підтримує своє здоров'я. Поле зору обмежене конусом у напрямку
погляду (fog of war). Стіни блокують огляд, вікна — ні.

### Інфраструктура міста

- **Дороги:** 2 горизонтальні + 2 вертикальні магістралі + 1 провулок
- **Тротуари** вздовж усіх доріг
- **~16 будівель** різних типів:
  - Сімейні будинки (carpet, кухня, ліжко, шафа)
  - Котеджі (простий інтер'єр)
  - Квартири (кахель, велика кухня, кілька ліжок)
  - Гаражі/склади (полиці з інструментами)
  - Клініки (аптечки, ліжка)
  - Магазини (полиці + кухонні шафи)
- **Вікна** на стінах будівель (кожні 3 тайли)
- **Дерева**, кущі, лавки, паркани — декорація
- **Смітники** вздовж тротуарів

## Персонаж

### Рух
- **WASD відносно погляду** — W = вперед (куди миша), S = назад, A/D = стрейф
- **Shift = біг** (200 px/s замість 120, витрачає більше голоду/спраги/сили)
- **Напрямок погляду** = позиція курсора миші (незалежний від руху)
- **Колізії** — перевірка 4 кутів bounding box, ковзання вздовж стін

### Характеристики виживання

| Стат | Початок | Зменшення | Критичний ефект |
|------|---------|-----------|-----------------|
| **HP** | 100 | Голод=0: -2/10с, Спрага=0: -3/10с | 0 = смерть |
| **Голод** | 80 | -1/30с (біг x2, вага>70% x1.5) | <30: рух -20%. 0: втрата HP |
| **Спрага** | 90 | -1/20с (біг x2.5) | <30: рух -25%. 0: втрата HP |
| **Втома** | 100 | Ходьба -0.5/хв, Біг -3/хв, Голод<30: -1/хв | <40: не може бігти. <20: рух -30% |

**Регенерація HP:** +0.5/2хв якщо голод>50 і спрага>50  
**Відновлення втоми:** +0.3/хв коли стоїш на місці

### Модифікатори на FOV
- Голод < 15 → радіус FOV -30%
- Втома < 10 → радіус FOV -40%

## Поле зору (Fog of War)

- **Конус ~120°** у напрямку курсора миші
- **DDA raycasting** — промені проходять кожен тайл на шляху (не пропускають стіни)
- **Периферійний зір** — короткі промені 360° (радіус 3 тайли), також wall-aware
- **Блокування зору:** стіни і дерева блокують, вікна і меблі — ні
- **3 стани тайла:**
  - **Visible** — в конусі зараз (повний колір)
  - **Explored** — був видимий раніше (затемнений, alpha 140)
  - **Unknown** — ніколи не бачений (майже чорний, alpha 245)
- **Реалізація:** Bitmap32 (80x60, 1 піксель на тайл), масштабований на весь світ

## Локалізація

Всі тексти гри винесені в JSON файли локалізації (`data/lang_XX.json`).

**Підтримувані мови:** English (`en`), Українська (`uk`)

**Що локалізовано:**
- HUD бари (HP, Hunger/Голод, Thirst/Спрага, Stamina/Сила)
- Промпти ([E] Search / [E] Обшукати, You died / Ви загинули)
- UI інвентаря (заголовок, кнопки Drop/Кинути, Eat/З'їсти, Drink/Випити, Use/Вжити)
- UI контейнерів (назви типів, кнопка Take/Взяти)
- Назви предметів (Flashlight/Ліхтарик, Bandage/Бинт тощо)
- Одиниці ваги (kg/кг)

**Використання в коді:**
```kotlin
Lang.load("uk")              // завантажити мову
Lang["hud.hunger"]           // → "Голод"
Lang["item.flashlight"]      // → "Ліхтарик"
stack.def.localizedName      // → локалізована назва предмета
```

**Додати нову мову:** створити `data/lang_XX.json` за шаблоном `lang_en.json`.

## Система предметів

### Формат items.json

```json
{
  "id": "canned_beans",
  "name": "Canned Beans",
  "description": "A can of beans. Can be eaten without cooking.",
  "weight": 0.4,
  "category": "food",
  "stackable": true,
  "maxStack": 5,
  "useAction": "eat",
  "hungerRestore": 25.0
}
```

Назва предмета в `items.json` — fallback. Локалізовані назви беруться з `lang_XX.json` → `item.<id>`.

### Предмети

| ID | Назва | Категорія | Вага | Дія | Ефект |
|----|-------|-----------|------|-----|-------|
| canned_beans | Консервовані боби | food | 0.4 | З'їсти | +25 голод |
| water_bottle | Пляшка води | food | 0.5 | Випити | +40 спрага, +10 голод |
| bandage | Бинт | medical | 0.1 | Вжити | +15 HP |
| screwdriver | Викрутка | tool | 0.3 | — | — |
| flashlight | Ліхтарик | tool | 0.2 | — | — |
| newspaper | Газета | junk | 0.1 | — | — |
| empty_can | Порожня банка | junk | 0.1 | — | — |
| old_shirt | Стара сорочка | clothing | 0.3 | — | — |
| kitchen_knife | Кухонний ніж | weapon | 0.3 | — | — |
| matches | Сірники | tool | 0.05 | — | — |

### Лут-таблиці

| Контейнер | Предмети (вага ймовірності) |
|-----------|---------------------------|
| **Смітник** | newspaper(30), empty_can(25), old_shirt(10), canned_beans(8), water_bottle(5), screwdriver(5), flashlight(2) |
| **Кухонна шафа** | canned_beans(25), kitchen_knife(15), matches(15), water_bottle(10), empty_can(10) |
| **Шафа** | old_shirt(40), flashlight(5), matches(5) |
| **Аптечка** | bandage(60), water_bottle(10) |
| **Полиця** | screwdriver(30), flashlight(15), matches(10) |

Кожен контейнер генерує 1–4 предмети при першому відкритті. Лут зберігається.

## Інвентар

- **Максимальна вага:** 15.0 кг
- **Стакання:** stackable предмети об'єднуються (до maxStack)
- **UI (Tab):** панель праворуч з категорійними кольорами
  - Зелений = food, Червоний = medical, Жовтий = tool, Помаранчевий = weapon, Блакитний = clothing
- **Кнопки:**
  - "З'їсти" / "Випити" / "Вжити" — для предметів з useAction (відновлює характеристики)
  - "Кинути" — видаляє предмет

---

## UI / HUD

### Бари характеристик (внизу-ліворуч)
- HP (червоний), Голод (помаранчевий), Спрага (синій), Сила (зелений)
- Ширина бару пропорційна значенню
- Колір змінюється: норма → жовтий (<30) → червоний (<15)
- Числове значення праворуч від бару

### Підказки
- `[E] Обшукати` — коли біля контейнера
- `Ви загинули...` — при HP = 0
